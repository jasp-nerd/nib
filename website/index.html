It does the twenty percent you actually use.

Everything below is in the first release. Everything not below is deliberate.

Requests are files

One JSON file each, in a folder you choose. Bodies live in sibling files, so a diff is readable. Rename one in Finder and it renames in the app.

Postman import

Collections v2.1 and v2.0, environments, and the whole data-dump zip. Drag it onto the window.

Environments

Swap {{baseUrl}} between local and staging. Secrets go to the Keychain and never to your files.

cURL both ways

Paste a command from Chrome, Firefox or Windows cmd. Copy one back out, with credentials redacted if you like.

Real response detail

JSON highlighting, headers, cookies, the redirect chain, and a timing waterfall from real URLSession metrics.

Keyboard first

Every action has a shortcut and every shortcut is a menu item. ⌘K jumps to any request in the collection.

Switching takes about a minute.

  1. Export from Postman.Settings → Data → Export, or right-click a collection and export it.
  2. Drop it on Nib.The whole window is a drop target. A zip, a collection, or an environment file — all fine.
  3. Read the report.Nib lists anything it cannot execute, by request name, and keeps it in your files untouched.
Collections Folders Environments Variables Auth Bodies Headers Scripts, preserved

Nib does not run scripts, and it says so rather than pretending. Anything it cannot execute round-trips untouched and is reported by name. An import never silently drops anything.

Install it in one line.

brew install nib-app/tap/nib

Nib is self-signed rather than notarized, and the tap clears the quarantine attribute for you. If you download the zip from GitHub instead, run xattr -dr com.apple.quarantine /Applications/Nib.app once. That is the honest cost of not paying Apple $99 a year.

Nib needs zero system permissions. No Accessibility, no Input Monitoring, no Screen Recording — there is nothing to grant.
